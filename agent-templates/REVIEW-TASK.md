# Senior Backend/Data Engineering Review

Review the current implementation.

Check:

1. data model correctness
2. normalization
3. primary/foreign keys
4. CHECK/UNIQUE/NOT NULL constraints
5. indexes
6. RLS
7. grants
8. transaction boundaries
9. race conditions
10. idempotency
11. SQL correctness
12. query performance
13. N+1 queries
14. validation
15. error handling
16. migration safety
17. data quality
18. test coverage
19. secret exposure
20. unnecessary complexity

Classify findings:
- CRITICAL
- HIGH
- MEDIUM
- LOW

For every finding:
- problem
- impact
- evidence
- recommended fix

Do not perform a redesign unless necessary.
